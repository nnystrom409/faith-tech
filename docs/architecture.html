How the onboarding bot is built

One Next.js app on Vercel. Chat SDK receives WhatsApp and SMS messages, AI SDK reads what the pastor wrote, plain TypeScript decides what gets saved, and a single store interface lets us run with or without a database.

Can the prototype run without a database?

Yes. For a 3‑minute demo with test data, no database is needed. The one catch is that plain in‑memory state only works when a single process handles every request. On Vercel, separate function instances don't share memory, so a webhook and the dashboard can see different data. Use in‑memory if you demo from next dev plus a tunnel, or Upstash Redis (one click in the Vercel Marketplace) if the demo runs on a deployed URL.

Supabase becomes necessary once organizers log in, data must outlive the event, or the dashboard needs real queries across churches and events. Write the code against one store interface now and the switch is a single file later.

When Supabase becomes needed

  • Regional organizers and church teams sign in and should see only their own churches.
  • Records must be kept past the demo, with history of corrections to reported counts.
  • The dashboard needs readiness, reporting coverage and follow‑up across many churches and shared events.
  • Multiple churches report into one event and you need a guarantee of no double counting.
  • You want reminders scheduled from event dates, which fits a table plus a cron job.

None of these show up in a 3‑minute demo, which is why Option A is enough today.

The store interface that keeps both doors open

Every handler calls these functions and never touches storage directly. The memory version is about 40 lines. The Redis and Supabase versions implement the same signatures, and an env var picks which one loads.

// lib/store.ts
export interface Store {
  recordConsent(phone: string, channel: "whatsapp" | "sms"): Promise<void>;
  optOut(phone: string): Promise<void>;
  upsertChurch(input: ChurchInput): Promise<Church>;       // flags likely duplicates
  saveReport(churchId: string, count: number): Promise<Report>;
  addTask(task: SupportTask): Promise<void>;              // low confidence, help requests
  dashboard(): Promise<DashboardSnapshot>;
}

export const store: Store =
  process.env.STORE === "supabase" ? supabaseStore
  : process.env.STORE === "redis"  ? redisStore
  : memoryStore;
